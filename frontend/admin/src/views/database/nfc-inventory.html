Hướng Dẫn Nạp Thẻ Trắng NTAG213 (UID Mirror)

Nạp 1 Link Mẫu Dùng Cho Hàng Nghìn Thẻ

Bạn không cần phải nạp link riêng cho từng cây! Nhờ tính năng UID Mirroring của chip NTAG213, bạn chỉ cần nạp 1 link duy nhất vào 1.000 thẻ trắng. Khi mang thẻ ra vườn cắm và quét, chip sẽ tự động điền mã UID để kỹ sư gán cây.

3 Bước Nạp Thẻ Bằng Điện Thoại (App NFC Tools - Miễn Phí):

  1. Bước 1: Mở app NFC Tools trên điện thoại → Chọn Write (Ghi) → Add a record (Thêm bản ghi) → Chọn URL / URI.
  2. Bước 2: Dán đường dẫn mẫu của trang trại:
    https://plant-book.onrender.com/1/public/00000000000000
  3. Bước 3: Bật tùy chọn "UID Mirror" (nằm trong phần Advanced / Mirroring) → Bấm Write và chạm lưng điện thoại vào từng thẻ trắng để nạp hàng loạt.
Tại vườn: Chỉ cần cắm thẻ vào gốc cây → cán bộ chạm điện thoại → chọn STT cây → Hệ thống tự động gán thẻ + lưu tọa độ GPS!
Sẵn sàng nhập kho (Dùng Web NFC trên điện thoại hoặc cắm đầu đọc USB để quẹt thẻ liên tục)
